## 1. 專案簡介與核心價值

在早期個人財務管理中，常見痛點包括：

- 依靠零散 Excel / CSV 試算表，缺乏先進先出 (FIFO) 庫存批次追蹤，歷史賣出真實獲利難以回溯。
- 銀行帳戶、即期信用卡負債與股票現值彼此割裂，無法掌握真正的「流動性防守縱深」。
- 市面記帳軟體多需上傳雲端，涉及高度隱私的個人資產數據有外洩風險。

**個人資產一體化工作台**徹底解決了上述問題：

* 🛡️ **100% 離線隱私優先**：財務資料均儲存在本地端檔案，無需任何第三方資料庫帳號或雲端訂閱。
* ⚡ **極致輕量與流暢體驗**：基於 Vanilla HTML5 + CSS3 + 原生 JavaScript 打造，無重型前端框架負擔，一秒瞬間啟動。
* 📈 **券商對帳單級精度**：內建台股標準手續費、證交稅試算、零股手續費整數分攤演算法，損益試算與真實券商 APP 100% 一致。
* 🌐 **智慧行情整合**：地端微服務無縫介接台灣證券交易所 (TWSE) 公開行情，隨時一鍵更新最新未實現損益。

## 2. 系統架構與運作原理

本系統採用標準的**「三層解耦架構 (Three-Tier Decoupled Architecture)」**，資料流向清楚且邏輯層層防呆：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   【展示與互動層】 Presentation Tier                     │
│  workbench.html ＋ workbench-app.js (現代暗黑玻璃擬態 / 5 大獨立視圖 SPA)  │
│  ├─ 總覽戰情 (水庫防守模型 / 年度戰果切換) ├─ 股票庫存 (雙直欄 / 雙維度排序)     │
│  ├─ 銀行資產 (5 類全圖示化標籤)         ├─ 交易紀錄 (摩擦成本 / 操作對齊)    │
│  └─ 已實現損益 (週期切片 / 盈虧圓餅圖)    └─ 滑出抽屜 (名稱智慧導流 / 負數防呆) │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 事件驅動 / DOM 雙向渲染
┌───────────────────────────────────▼────────────────────────────────────┐
│                 【金融計算核心引擎層】 Core Engine Tier                   │
│  workbench-engine.js (無 DOM 純邏輯運算 / 10 大單元測試 100% 覆蓋)        │
│  ├─ FIFO 先進先出庫存沖銷與損益撮合     ├─ 券商標準整數分攤 (低消/稅率/零股) │
│  ├─ 歷史任意基準日月末估值回溯推算     ├─ 實質流動性防守縱深與破防警戒運算   │
│  └─ 雙維度標的排序演算法 (金額 vs 效率) └─ 自動學習字典與異常超賣防護攔截   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 300ms 本地防抖 ＋ 異步 RESTful API
┌───────────────────────────────────▼────────────────────────────────────┐
│                    【資料與持久化層】 Data & Service Tier                 │
│  1. 地端 IndexedDB 快取 (AssetWorkbenchDB) ──> 支援離線極速秒開          │
│  2. 原生 Node.js 微服務 (server.js:8080)                                │
│     ├─ TWSE 證交所即時現價與歷史收盤價 API 轉接                         │
│     ├─ POST /api/save-bank-assets ──> 原子化寫入磁碟實體 JSON           │
│     └─ POST /api/save-snapshots   ──> 寫入月度持股市值與結算快照        │
│  3. 單一真理來源 (Single Source of Truth): assets_data.json (UTF-8 BOM)│
└────────────────────────────────────────────────────────────────────────┘
```

### 核心運作機制解密

1. **單一資料來源 ＋ 雙重持久化 (Dual Persistence Sync)**：
   - 應用程式啟動時，優先由 IndexedDB 讀取快取迅速呈現介面，背景同步獲取伺服器端 [assets_data.json](file:///c:/person/Me/Money/person_dashboard/assets_data.json) 最新快照進行校準。
   - 使用者編輯帳戶或新增交易時，前端觸發 300ms 自動防抖存檔至 IndexedDB，並透過後端 RESTful API 實體寫入磁碟 JSON 檔案，確保重啟服務或重新整理資料永不遺失。
2. **純純粹粹的計算解耦 (Decoupled Engine)**：
   - [workbench-engine.js](file:///c:/person/Me/Money/person_dashboard/js/core/workbench-engine.js) 為純 JavaScript 類別，不依賴任何瀏覽器 DOM 物件或第三方套件，兼具極高的運算效能與 100% 自動化單元測試覆蓋能力。
3. **無痛升級與歷史兼容**：
   - 完整相容既有歷史 CSV 對帳單格式，支援 Excel 友善的 UTF-8 with BOM 雙向匯出與匯入。

## 3. 五大業務視圖與功能特色

工作台採用現代化全寬度單頁應用 (SPA) 佈局，頂部導航列提供 5 大專業視圖一鍵切換：

### 1️⃣ 總覽儀表板 (`#view-overview`)

* **淨資產圓環看板**：採用 Chart.js 甜甜圈圖，中心清晰呈現「總資產淨值」，並外環動態展現「純存款」與「股票持股市值」配比。
* **🛡️ 財務安全防守線（水庫防守覆蓋模型）**：
  - 揭露「實質可用流動現金」、「信用卡應繳負債」與「流動負債比率」。
  - **正常充足時**：藍色條顯示扣除即期負債後的實質安全厚度，紅色條顯示負債侵蝕率。
  - **超額負債赤字時**：藍色水位自動歸零 (`0.0% 防線遭擊穿`)，整條滿載深紅警戒條 (`100.0% 超額負債`)，並觸發動態破防警戒評語。
* **⚔️ 年度戰果看板**：
  - 支援智慧年份動態錨定與隨時切換（如切換 2025、2026 年度）。
  - 精準彙總當年度「淨資產增長」、「已實現平倉獲利」與「平倉戰績勝率（幾勝幾負）」。
* **月度結算總表**：預設收合僅顯示近 3 個月歷史結算快照，支援一鍵展開/收合全部歷史數據。

### 2️⃣ 銀行資產頁面 (`#view-bank`)

* **5 類全圖示化標籤**：
  - 💰 **活存** (`活存`)：薄荷翠綠
  - 🏦 **定期存款** (`定存`)：琥珀金色
  - 📈 **證券交割** (`證券交割`)：天空藍色
  - 🌐 **外幣帳戶** (`外幣`)：紫羅蘭色
  - 💳 **信用卡/負債** (`負債`)：警示緋紅色（金額自動防呆取負值）
* **銀行佔比甜甜圈圖與排行**：依折合台幣餘額降冪排列各大主力存款銀行，支援零餘額帳戶收納。
* **月份快照切換**：隨時切換查看歷史任一對帳日的銀行存款與負債結構。

### 3️⃣ 股票持倉頁面 (`#view-stock`)

* **3 大持倉核心 KPI**：即時呈現「持股市值」、「投入總成本」與「帳面未實現損益」（遵循台灣證券習慣：**紅色獲利賺、綠色虧損賠**）。
* **雙直欄獨立排版**：明細表獨立呈現「成本均價 / 最新現價」與「投入總成本 / 持股市值」，徹底擺脫傳統雜亂表格。
* **雙維度對稱排序**：
  - 金額維度：📈 未實現損益 (由大到小) ｜ 📉 未實現損益 (由小到大)
  - 投報效率：🚀 報酬率 (由高到低) ｜ 🪂 報酬率 (由低到高)
* **⚡ 一鍵更新現價**：透過地端微服務向證交所 API 批次抓取最新成交市價，重新計算未實現損益。

### 4️⃣ 交易紀錄頁面 (`#view-history`)

* **金流摩擦成本看板**：彙整累計買入、累計賣出、手續費總和、證交稅總和與總摩擦成本率。
* **標籤與按鈕規範**：
  - 買賣方向標籤：**🔴 買入 (紅底)**、**🟢 賣出 (綠底)**。
  - 操作列絕對齊平：採用固定寬度 Flex 右錨定容器，無論該列為 2 顆按鈕或 3 顆按鈕，`🗑️ 刪除` 與 `✏️ 編輯` 垂直方向 100% 絕對齊平，徹底消除視覺鋸齒感。
  - 快速直達穿透：賣出單提供 `🔍 查平倉`，買入在庫單提供 `📦 庫存` 跳轉。

### 5️⃣ 已實現損益頁面 (`#view-pnl`)

* **快捷週期標籤組**：一鍵切換 `全部`、`今年 YTD`、`近 1 年`、`近 3 個月`、`本月` 或自訂日期範圍。
* **獲利貢獻佔比圖 (Profit Weight Chart)**：直觀呈現各飆股在總已實現獲利中的貢獻佔比。
* **平倉排行榜與個股過濾**：點擊排行榜個股即可一鍵穿透篩選該標的所有平倉明細。

## 4. 金融計算引擎規格 (Financial Engine Spec)

所有核心商業邏輯收斂於 [`WorkbenchEngine`](file:///c:/person/Me/Money/person_dashboard/js/core/workbench-engine.js)，遵循嚴格的台灣證券與會計標準：

1. **先進先出 (FIFO) 批次沖銷演算法**：
   - 當發生「賣出」交易時，由最早買入的批次依序扣減股數。
   - 賣出單價扣除先進批次的成本均價，扣除手續費與證交稅後，得出該筆平倉之 `netProfit`（淨損益）與 `profitRate`（報酬率）。
2. **手續費與證交稅法規精算**：
   - 買賣手續費率預設 $0.1425\%$，並強制設有最低低消 $20$ 元新台幣。
   - 股票賣出證交稅率 $0.3\%$（ETF 為 $0.1\%$）。
3. **零股尾數結轉與整數分攤模式**：
   - 針對同一筆交易分次平倉（如零股賣出 2 股與 98 股），手續費與成本採用四捨五入整數化，最後剩餘尾數於末筆完全沖銷，保證與券商對帳單每塊錢完全吻合。
4. **超賣防護機制 (Oversell Prevention)**：
   - 當賣出股數大於現有累計庫存時，引擎自動攔截並拋出清晰異常，嚴防負庫存破壞資料模型。

## 6. 快速啟動指南 (Quick Start)

### 環境需求

* **作業系統**：Windows 10 / 11（繁體中文環境）
* **執行環境**：Node.js v16.0.0 以上

### 一鍵啟動方式

* **🚀 日常極簡無痕啟動（推薦）**：
  直接雙擊專案根目錄的 **`Start-Workbench.vbs`**。完全不彈出黑底命令提示字元視窗，純背景喚醒 Node.js 並自動開啟瀏覽器。
* **⚡ 備用命令列啟動**：
  雙擊 **`Start-Workbench.bat`**。
* **🛑 停止背景服務**：
  關閉所有工作台網頁分頁後，背景伺服器將在 **30 秒**後自動釋放 Port 8080 並安全退場；亦可隨時點擊 **`Stop-Workbench.bat`** 立即強制停止。

直接於瀏覽器造訪：
👉 **`http://127.0.0.1:8080/workbench.html`**

## 8. 開發與編碼規範 (Development Guidelines)

參與維護與修改本系統時，必須嚴格遵守以下開發守則：

1. **檔案編碼強制規範**：
   - 所有的 `.html`、`.js`、`.json`、`.md`、`.ps1` 檔案**強制採用 UTF-8 with BOM (Byte Order Mark)** 編碼儲存。
   - 【絕對禁止】使用無 BOM 的 UTF-8，以防止 Windows PowerShell 5.1 解析繁體中文字串時發生語法報錯或亂碼。
2. **純粹無外部框架原則**：
   - 前端堅持使用原生 Vanilla HTML/CSS/JS，保持輕盈秒開特性。
   - 第三方視覺庫僅採用已地端化的 [Chart.js](https://www.chartjs.org/)，不任意引進龐大套件袱包。
3. **金融資料修改三不原則**：
   - 嚴禁直接在 UI 層計算複雜損益，所有商業會計邏輯必須收斂於 `WorkbenchEngine`。
   - 任何改動不得破壞歷史快照與單元測試套件的正確性。
